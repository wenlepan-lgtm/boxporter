# ADR-014：可恢复单机与高可用边界

- 状态：Accepted
- 日期：2026-08-14

## 上下文

V1 部署在单台 Mac mini，家庭供电与公网线路不稳定；断电/断网期间控制台可能不可用，但恢复后状态与证据不得丢失或重复。

## 决策

- V1 目标是“可恢复的高可靠单机”，不是高可用集群：launchd KeepAlive 守护、宿主重启后 reconciliation、UPS/断电恢复、加密备份、外部健康探针。
- 可靠性硬指标（规划书 §4.6）：已提交事务状态丢失 0；同任务同角色重复有效 Lease 0；Daemon 异常退出 60s 内重启；宿主重启 5min 内完成 reconciliation；PASS 证据 100% 可重算哈希；备份 RPO ≤24h、PASSED 封箱后立即进备份队列；灾难恢复 RTO ≤2h。
- 跨主机无缝接管（PostgreSQL/Temporal）明确延期。

## 后果

- 用户对可用性有清晰预期；达不到指标时缩小范围，而不是降低审核/权限门槛。
- 恢复演练（数据库恢复、migration 校验、证据哈希重算、箱子投影重建、过期 Lease 不恢复）至少每月一次。
