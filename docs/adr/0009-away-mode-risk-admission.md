# ADR-009：Away Mode 风险准入与默认禁止动作

- 状态：Accepted
- 日期：2026-08-14

## 上下文

无人值守若默认放权，会出现 Token 失控、重复执行、越权操作与不可逆外部影响。规划书要求“无人值守，但不能无人监管”。

## 决策

- 三种运行策略：SUPERVISED / AWAY / PAUSED；切换只改变调度与审批策略，不删除状态、不绕过审核。
- 任务进入无人值守执行必须满足全部准入条件（READY、依赖满足、风险 ≤ Away Policy 允许级、无生产写入、无不可逆外部操作、预算充足、工作区干净或隔离、验收可自动执行、凭据安全引用、Runner 健康、无同角色有效 Lease）。
- 权限分级：READ_ONLY / WORKSPACE_WRITE / NETWORK_RESTRICTED / EXTERNAL_WRITE / SYSTEM_ADMIN / PRODUCTION；AWAY 默认仅允许前三级。
- 默认禁止：删大范围数据、推送/部署生产、外部发送、改安全设置、未授权 sudo、自动扩大预算、绕过证据门、脏工作树上覆盖、因用户离线而降低安全门槛。
- 审批必须绑定：动作、精确目标、角色与 Run、最大次数、有效期、风险、影响与回滚方式。

## 后果

- “无人值守”是预算与权限边界内的持续推进，而不是最大化模型调用。
- 安全停止（BLOCKED/WAITING）优于失控推进。
