# ADR-012：任意地点 Web 访问、设备会话与身份边界

- 状态：Accepted
- 日期：2026-08-14

## 上下文

用户需要在任意地点安全登录查看实时过程并控制。裸端口 + 弱认证不可接受；浏览器只是控制端，断开不影响执行。

## 决策

- 访问方案优先级：Tailscale/WireGuard 私人网络 → 身份感知 Tunnel（MFA + 访问策略）→ FRP + Caddy/Nginx + HTTPS + 强认证 → SSH Local Forward（仅运维应急）。
- Web UI 默认只监听 127.0.0.1；不直接把端口裸露公网。
- 应用层必须：HTTPS、登录会话、MFA/二次认证能力、CSRF 防护、限流、操作审计；设备会话可查看/过期/远程撤销；WebSocket 使用与页面相同认证，禁止匿名订阅。
- 高风险操作（批准、改 Secret、远程停止系统）需要重新认证。
- 浏览器关闭、换设备、断网都不改变任务生命周期。

## 后果

- 便利性不牺牲控制安全；远程操作 100% 审计（操作者、目标、结果、时间）。
- 用户在任何地点看到的是服务端同一真相。
