# ADR-013：WebSocket 事件游标与断线补发

- 状态：Accepted
- 日期：2026-08-14

## 上下文

Web 实时页断开时必须能从最后确认游标补齐事件，页面最终与服务端状态一致；浏览器断开不能把 Run 标记为失败。

## 决策

- 事件以 Event Log 递增 seq 为游标；客户端订阅 `GET /api/events/stream?after_cursor=` 并维护 last_confirmed_seq。
- WebSocket/SSE 断开后前端自动重连（10 秒内），从 last_confirmed_seq 补发缺口；事件缺口必须为 0。
- 前端只发送命令（幂等键 + 版本检查），服务端验证权限与合法迁移；前端永远不直控子进程、不以本地缓存推断状态。
- Run 生命周期与任何浏览器连接解耦。

## 后果

- 断网重连后的状态一致性与缺口由服务端事件序列保证，可测试、可度量。
- 事件保留策略需平衡存储与补发窗口（默认：近期事件全量、归档事件压缩）。
